# El Sewedy International School (IATS) - Web Portal

An interactive web platform for **El Sewedy International School for Applied Technology & Software (IATS)**, Egypt.

## 🚀 Key Features

- **Academic Specializations**: Interactive curriculum breakdown for **Computer Science (CS)** and **Electronic Systems (ES)** across 3-year progression.
- **Campus & Facilities**: Showcase of engineering Fab Labs, CDC (Career Development Center), PHP (Peer Helping Program), Arts studios, and Athletics Hub.
- **Special Moments & Honors**: Historic visits (including U.S. First Lady Dr. Jill Biden) and the El Sewedy ICPC Problem-Solving Championship.
- **Interactive UI**: Kinetic momentum scrolling powered by Lenis, animated statistics counter, and responsive mobile navigation.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis
- **Styling**: Modern CSS Design System (Custom Variables, Glassmorphism, Micro-animations)

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <YOUR_REPO_URL>
cd elsewedy-school-profile
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
